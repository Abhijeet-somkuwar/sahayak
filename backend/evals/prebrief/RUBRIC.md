# Pre-brief clinician rubric (§10.7)

Score each generated pre-brief (50 synthetic contexts) 1–5 on usefulness; pass = median ≥ 4/5 and **zero** fabricated allergies or medicines.

| Score | Meaning |
|---|---|
| 5 | Headline exact; every key point is correct, relevant and cited; questions are the ones I would ask |
| 4 | Minor omission; nothing wrong |
| 3 | Correct but generic; adds little beyond the deterministic block |
| 2 | A point is misleading or irrelevant |
| 1 | Any fabricated fact (the validator should have removed it: file a bug) |

The deterministic block is never scored here: it is rendered from SQL rows and is correct by construction.
